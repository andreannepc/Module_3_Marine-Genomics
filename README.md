# Module_3_Marine-Genomics

This module introduced marine genomics and metagenomic bioinformatics, progressing from Unix command-line skills and biological sequence files to genome assembly, quality assessment, metagenomic binning, taxonomic classification and functional annotation. Across four workshops, I applied tools including Flye, Bandage, MetaBAT2, CheckM, GTDB-Tk, Prokka and MinPath to explore microbial genomes and ultimately investigate the composition and potential functions of microorganisms associated with coral black band disease.
